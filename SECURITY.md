# Security

This alpha is for trusted local evaluation. The shared API key grants service-wide access, not tenant authorization. Do not expose it directly to untrusted users.

Do not disclose secrets or customer data in public issues. Use GitHub private vulnerability reporting if enabled; otherwise contact the maintainer privately before publishing exploit details. No response SLA is guaranteed.

Known deployment gaps are listed in docs/operations.md. Schema validation and prompt instructions do not formally prevent malicious input or model errors.
