# 한국어 안내

**종료 대화 → 여러 고객 요청 요약 → 지속적인 주제 분류** 구조입니다. 기존 주제 분류를 재사용하고, 미할당 요청은 제한된 배치로 분석해 신규 등록 여부를 판단합니다. 상위 분류는 현재 제외하며 추후 별도 관계로 추가할 수 있습니다.

- 생성과 임베딩을 따로 설정합니다. Ollama native API, vLLM 등의 OpenAI 호환 API 어댑터를 제공합니다.
- Repository 인터페이스와 SQLAlchemy 어댑터로 DB를 분리했습니다. SQLite 기본, PostgreSQL·MySQL 선택 설치입니다. DB URL 변경은 데이터 마이그레이션이 아닙니다.
- 종료 대화는 API/JSONL로 등록하고 별도 worker가 처리합니다. 동일 입력은 중복 처리하지 않고 변경된 입력은 거절합니다.
- 개별 요청 벡터는 일시 계산하고 주제 대표 벡터만 저장합니다. 원문·요약·연결은 남으므로 별도 보존 정책이 필요합니다.
- 주제 수·미할당 기한·검토 횟수·배치 크기는 설정으로 제한합니다.
- TOP 10은 실제 세션 종료일 기준의 고유 세션 수이며 원문은 페이지 단위로 조회합니다.

현재는 **실험용 alpha**입니다. 운영 인증·테넌트별 권한, 스키마 이행, 삭제·편집 전파, 모델 변경 이행과 장기 성능 검증은 아직 없습니다. demo provider는 합성 예시용 규칙 기반 fixture이며 실제 모델이 아닙니다. 연구 메모·논문 PDF·DSTC12 원문을 포함하지 않습니다.

설치·설정은 [README](../README.md), 경계는 [설계](architecture.md), 운영 제한은 [운영 문서](operations.md)를 참고하세요.
